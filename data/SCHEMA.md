# `window.SUDAN` — data contract (Sudan v0)

Generated by `scripts/build_sudan.py` → `data/sudan_core.json`, then inlined into
`data/bundle.js` by `scripts/build_bundle.py` as the global `window.SUDAN`.
The bundle is additive: the legacy `window.SD_*` globals (used by the v0
`index.html`) are **kept untouched**; `window.SUDAN` is the new normalized object
the full-site UI should code against.

Build date: 2026-10-27. Data window: UCDP 2024-01-01 → 2026-09-28, FIRMS last 90 days.

```
window.SUDAN = {
  meta, events, states,
  fires_density, fires_conflict_recent, fires_history, fires_timeline,
  timeline, focus, boundaries_url, boundaries, control
}
```

> **2026-10-28 enrichment (additive, retro-compatible):** data window now starts
> at the **war outbreak 2023-04-15** (was 2024-01-01); `events` 1320→**1626**.
> New fire fields: **`fires_conflict_recent`** (explicit conflict-fire subset),
> **`fires_history`** (annual 0.1° grid, FIRMS SP archive), **`fires_timeline`**
> (monthly totals + `north`≥12N subset). `boundaries.neighbors` added (7 ADM0
> context outlines). `meta.bbox` extended south to `[21.8, 8.2, 39.1, 22.3]`.
> Legacy fields unchanged. See `data/AUDIT.md`.

## `meta`
```
{
  generated:        "YYYY-MM-DD",            // build date
  updated_through:  "YYYY-MM-DD",            // last UCDP event date (= 2026-09-28)
  bbox:             [lon_min,lat_min,lon_max,lat_max],  // [21.8,8.6,39.1,22.2]
  fires_days:       90,
  fires_window:     ["YYYY-MM-DD","YYYY-MM-DD"],        // FIRMS min/max acq date
  counts:           { events, states, fires_cells, fires_near_conflict_cells,
                      fires_detections, timeline_months },
  guardrail:        "...",                   // plain-text statement of the Darfur rule
  sources:          [ {name, license, url, date}, ... ]
}
```
**Sources / licenses (verified):**
- **UCDP GED v25.1 (stable) + Candidate v25/v26 (monthly)** — license **CC BY 4.0** — https://ucdp.uu.se/downloads/
- **NASA FIRMS VIIRS SNPP NRT** — **public domain** (NASA EOSDIS/LANCE; attribution requested) — https://firms.modaps.eosdis.nasa.gov/
- **geoBoundaries ADM0/ADM1 (Sudan)** — license **CC BY 4.0 (Open)** — https://www.geoboundaries.org/

Attribution for each must be shown in the UI footer / methodology page.

## `events` — armed clashes, geolocated points
Array of:
```
{ lon, lat, date:"YYYY-MM-DD", pair:"SAF vs RSF", deaths:<int best>, type:1|2, state }
```
- **Provenance:** UCDP GED. `type` = UCDP `type_of_violence`: **1 = state-based**,
  **2 = non-state**. `deaths` = UCDP `best` fatality estimate. `pair` is a readable
  actor label (SAF / RSF / named group / "X -> civilians" only in `states`, never here).
- **Volume:** 1320 points, 2024-01-01 → 2026-09-28 (1268 type-1, 52 type-2).
- **DARFUR GUARDRAIL (hard rule):** UCDP **type 3 (one-sided violence against
  civilians) is NEVER present in `events`** — zero points. Verified: no type-3,
  no "civilians" as a point target. Civilian violence appears **only** aggregated
  in `states` (see below). This avoids fine-grained localisation of atrocities /
  IDP camps while still letting the UI show its scale at state level.
- **Limits:** UCDP is event-coded from reports → under-counts in media-dark areas,
  coordinates have variable precision (point = reported locality centroid, not GPS),
  fatality `best` is an estimate. Candidate months (2025–2026) are **not yet final**.

## `states` — ADM1 aggregates (the ONLY place civilian violence is represented)
Array, sorted by activity, of:
```
{ name, adm1_id, events, deaths, civ_violence, civ_deaths }
```
- `adm1_id` = geoBoundaries ISO-3166-2 code (e.g. `SD-DN` North Darfur); `null` for
  "Unknown" (events whose ADM1 UCDP could not resolve).
- `events`,`deaths` = clash (type 1/2) counts/fatalities in that state.
- `civ_violence` = **count of type-3 civilian-targeted events** in that state;
  `civ_deaths` = their summed `best` fatalities. 19 states; 423 civ events /
  8993 civ deaths total, concentrated in North Darfur (81 events / 4233 deaths).
- **Limits:** state-level only by design; `civ_*` is the aggregated footprint of
  atrocities, never a point layer.

## `fires_density` — NASA FIRMS 90-day active-fire density grid
Array of ~5.5 km cells:
```
{ lon, lat, weight:<detections in cell>, near:<bool> }
```
- **Provenance:** VIIRS SNPP NRT, last **90 days** (fetched in ≤5-day chunks — the
  NRT area API caps the day range at 5), snapped to a 0.05° grid. 56 219 raw
  detections → 6986 cells. `weight` = detection count (seasonal agricultural
  burning dominates the south → high weights there are NOT conflict).
- `near` = cell within **15 km** of a clash event from the **last 60 days** — a
  distinct "fire near recent conflict" hint (104 cells). Treat `near:true` as a
  weak corroboration signal, **not** proof of conflict-caused fire.
- **Limits:** FIRMS detects **heat, not cause**; clouds suppress detections; NRT is
  preliminary. Never label a fire as a strike/burning of a village. Caveat must be
  shown on the map.

## `fires_conflict_recent` — conflict-fire subset (EXPLICIT, named)
Array of `{ lon, lat, weight }`: the cells of `fires_density` that lie within
**15 km of a clash in the last 60 days**. This is the UI's "fires near recent
fighting" layer, kept **apart** from the agricultural burning that dominates
`fires_density`. A weak corroboration hint, **never** proof of a conflict-caused
fire. See `meta.fires_note`.

## `fires_history` — time-aware fire archive (FIRMS VIIRS_SNPP_SP)
Array of 0.1° (~11 km) cells:
```
{ lon, lat, y:{ "2023":n, "2024":n, "2025":n, "2026":n }, total, north:<bool> }
```
- Built by `scripts/fetch_firms_archive.py` (SP archive 2023-04 → 2026-07) +
  recent NRT months. `north:true` = centroid ≥12N, i.e. **outside** the far-south
  seasonal agricultural-burning belt. Cells with <2 total detections dropped.
- Lets the UI offer a yearly time-slider instead of a single 90-day snapshot.
- Same caveat as all FIRMS: heat, not cause.

## `fires_timeline` — monthly fire series (seasonality)
Array `{ month:"YYYY-MM", all, north }`, 2023-04 → latest. `all` = all detections
that month; `north` = subset ≥12N. The gap between `all` and `north` is the
seasonal agricultural burning of the south — plotting both makes the distinction
honest and visible.

## `timeline` — monthly series (for the trend chart)
Array, chronological:
```
{ month:"YYYY-MM", events, deaths, civ_events, civ_deaths }
```
- 33 months, 2024-01 → 2026-09. `events`/`deaths` = clashes (matches the points
  layer); `civ_events`/`civ_deaths` added so the UI can optionally stack civilian
  violence. Last ~1–2 months are provisional (UCDP Candidate not finalized).

## `focus` — hot sectors (bbox + note)
Array of:
```
{ key, label, bbox:[west,south,east,north], note }
```
Two sectors: `kordofan` (El-Obeid / Bara axis) and `el_fasher` (North Darfur).
Use `bbox` to fit/zoom; `note` is a short French caption.

## `boundaries_url` / `boundaries`
- `boundaries_url` = `"data/boundaries/sudan_adm1.geojson"` (back-compat single URL).
- `boundaries` = `{ adm0, adm1, neighbors }` relative paths to geoBoundaries
  GeoJSON in `data/`. Loaded at runtime (large; files, not inlined in SUDAN).
  `neighbors` = ADM0 context outlines of South Sudan, Chad, Egypt, Eritrea,
  Ethiopia, CAR, Libya (geoBoundaries gbOpen CC BY 4.0, ~1 km simplified). Also
  exposed as `window.SD_NEIGHBORS` for the file:// bundle.

## `control` — **`null`** (honest default)
A SAF/RSF territorial-control layer is **not** provided: `control === null`.

**Why null.** A defensible control layer requires *tracing* polygons from a real,
dated, citable public map (Sudan War Monitor, Thomas van Linge, Sudans Post, etc.).
In this build environment there is no way to georeference and trace such a source
map to real coordinates; any polygon written here would be **invented**, which the
brief explicitly forbids ("une ligne inventée est interdite"). An honest sketch
needs a traced source, so control is left null rather than fabricated.

**If added later** (format the UI should expect):
```
control: [ { date:"YYYY-MM-DD", actor:"SAF"|"RSF", source:"<name+url>",
             approx:true, geojson_url:"data/control_<...>.geojson" }, ... ]
```
Each polygon file must be a coarse, approximate tracing of a single cited public
map, tagged `approx:true`, with balanced SAF/RSF coverage and a visible disclaimer.

## Regenerating
```
# 1. FIRMS 90d (key from ~/.config/firms/credentials, NEVER written into soudan/)
set -a; source ~/.config/firms/credentials; set +a
python3 -I scripts/fetch_firms.py <abs>/soudan/data/raw/firms 90 firms_raw_90d.geojson
# 2. legacy grids (optional, refreshes window.SD_FIRMS from 90d)
python3 -I scripts/process_grids.py <abs>/soudan/data firms_raw_90d.geojson
# 3. enriched contract object
python3 -I scripts/build_sudan.py <abs>/soudan <abs>/soudan/data/sudan_core.json
# 4. bundle (legacy SD_* + window.SUDAN)
python3 -I scripts/build_bundle.py <abs>/soudan/data <abs>/soudan/data/bundle.js
```
All scripts run with `python3 -I` and take paths as arguments (downloaded data is
untrusted; never run an interpreter from inside `data/raw/`). The FIRMS key is read
from `~/.config/firms/`, never stored in `soudan/`.
```
